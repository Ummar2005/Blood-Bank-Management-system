# Blood Bank Management System

A web-based Blood Bank Management System developed as a college project to manage blood donors, receivers, hospitals, blood requests, and blood stock.

## 🎓 Project Details

- **Project Type:** Web Application
- **College:** SJMIT
- **Branch:** Computer Science and Engineering
- **Technology:** PHP, MySQL, HTML, CSS, Bootstrap, JavaScript
- **Database:** MySQL
- **Development Environment:** XAMPP
- **Hosting:** InfinityFree

## 🚀 Features

- Admin Login and Dashboard
- Hospital Registration and Login
- Hospital Dashboard
- Receiver Registration and Login
- Donor Registration and Login
- Blood Stock Management
- Blood Request Management
- Accept/Reject Blood Requests
- Hospital Location Map
- Email/OTP functionality
- PDF Report Generation
- Responsive Bootstrap UI

## ⚙️ Installation

1. Install XAMPP.
2. Start **Apache** and **MySQL**.
3. Copy the project into:

   `C:\xampp\htdocs\blood_project`

4. Create a MySQL database.
5. Import the SQL file from the `sql` folder.
6. Configure the database connection.
7. Open:

   `http://localhost/blood_project/`

## 🔐 Security

Database passwords, email passwords, API keys and other sensitive credentials should not be committed to GitHub.

Use a configuration file that is excluded from Git using `.gitignore`.
